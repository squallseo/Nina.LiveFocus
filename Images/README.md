# Live Focus brand assets

- `live-focus-featured-v1.png`: square representative artwork, with the **Live Focus** name. Used by the plugin's `FeaturedImageURL` metadata.
- `live-focus-icon.svg`: transparent, scalable companion mark. Set `color` to change its fill; the default is ROI yellow (`#FFD54F`).
- `live-focus-icon-256.png`: transparent PNG of the companion vector mark.
- The dockable's WPF `GeometryGroup` uses the same SVG paths and the host's theme color for clear small-size rendering. It has no raster background or lettering.

The motif combines a play triangle, an open focus ring and a four-point star. The representative artwork was generated with the built-in image generation tool; the SVG and WPF geometry are manually authored companion assets. The full generation prompt is saved in `live-focus-featured-v1.prompt.txt`.
